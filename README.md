# Nafel - Environmental Events Platform

##  Overview
Nafel is a web-based platform that connects users with environmental and volunteer events in Riyadh. It allows users to discover events, register for participation, and earn points and certificates for their contributions.

---

## Features
- Browse and search for environmental events
- Register for events بسهولة
- View upcoming and past events
- Earn points and badges based on participation
- Receive certificates after completing events
- Create and manage events (for organizers)
- Admin approval system for events

---

## System Structure
The system is built using a relational database with the following main entities:
- User
- Event
- Registration
- Certificate

  ---

## Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: MySQL
